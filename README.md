<h1>📖 Descrição</h1>
Este repositório contém uma simples implementação do clássico jogo Jokenpô (Pedra, Papel e Tesoura) para web. O usuário escolhe uma opção, o computador faz sua jogada aleatoriamente e o resultado é exibido em tempo real.

<h2>🚀 Tecnologias</h2>

<b>HTML5:</b> marcação semântica do jogo.

<b>CSS3:</b> estilização responsiva e animada da interface.

<b>JavaScript:</b> lógica do jogo, geração aleatória de jogadas e interação.

<b>📂 Estrutura de Pastas</b>
````
jokenpo-web/
├── index.html        # Página principal do jogo
├── css/
│   └── style.css     # Estilos (layout e design)
├── js/
│   └── main.js       # Lógica e interatividade do Jokenpô
└── assets/
    └── images/       # Imagens e ícones usados no jogo
````

<p>Esta estrutura organiza o projeto em HTML, CSS e JavaScript, com uma pasta extra para armazenar recursos visuais (assets), facilitando futuras manutenções e expansões.</p>


<b>🛠️ Como Jogar</b>

Clique em Pedra, Papel ou Tesoura.

O computador escolherá aleatoriamente sua jogada.

O resultado (vitória, derrota ou empate) aparecerá na tela.

Para jogar novamente, basta clicar em outra opção.

<h3>✨ Recursos e Funcionalidades</h3>

Design responsivo para <b>desktop e mobile.</b>

Animações suaves ao selecionar opções.

Placar dinâmico para acompanhar vitórias, derrotas e empates.

Código limpo e comentado para facilitar contribuições.
